# 安全设计

## 信任模型

```text
┌── 本机信任域 ──────────────┐
│ Agent 状态库（只读）        │
│ schema 白名单              │
│ 密钥永不出域                │
└────────────┬───────────────┘
             │ 仅白名单字段
             ▼
┌── 传输域 ─────────────────┐
│ Tailscale WireGuard       │  端到端加密
│ tailnet ACL 身份验证        │  谁能连由 ACL 决定
│ 应用层 HMAC 签名            │  纵深防御
└────────────┬───────────────┘
             ▼
┌── 对端信任域 ──────────────┐
│ 验签 → 去重 → 落库          │
│ 失败即丢弃，不落库           │
└───────────────────────────┘
```

## 关键约定

### 1. 凭据永不同步

采集端**按 schema 白名单读取字段**。密钥、Token、Cookie、API Key 类字段
不会出现在 `audited_schema` 中，因此在 schema 层就被拒绝——**根本不会被读取**。

这不是"读了再过滤"，而是"不读"。两者安全性差别很大：

```text
✗ 读取全库 → 过滤掉密钥 → 发送    （密钥曾进入进程内存）
✓ 按白名单只读取需要的字段          （密钥从未被读取）
```

### 2. 只读访问源库

采集端以只读模式打开 Agent 状态库，不加写锁，不影响 Agent 正常运行。

### 3. 密钥不入仓库

- `.gitignore` 屏蔽 `*.key`、`*.env`、`*.db`、`receiver.json`、`collector.json`
- 仓库只提供 `*.example` 模板
- 密钥通过带外方式交换

### 4. 服务不暴露公网

接收端与代理**只监听 `127.0.0.1` 或 Tailscale 网卡地址**，不监听 `0.0.0.0`。
无公网端口，无公网 IP 也能工作。

### 5. 验签失败即丢弃

签名不合法的消息不落库、不返回详细错误（避免给攻击者提供反馈信号）。

## 威胁模型

| 威胁 | 防护 | 状态 |
|---|---|---|
| 传输被窃听 | WireGuard 端到端加密 | ✅ |
| 中间人伪造消息 | HMAC 签名 | ✅ |
| 非 tailnet 设备接入 | Tailscale ACL + 监听地址限制 | ✅ |
| tailnet 内异常设备 | 应用层 HMAC（纵深防御） | ✅ |
| 重放攻击 | 单调序列号去重 | ✅ |
| 凭据泄露 | schema 白名单，不读取密钥字段 | ✅ |
| 仓库泄露密钥 | `.gitignore` 屏蔽 | ✅ |
| 端口暴露到公网 | 仅监听内网/回环地址 | ✅ |
| 日志泄露敏感数据 | 日志不含 payload 内容 | ⚠️ 需自行审查 |
| 本机被入侵 | **不在防护范围** | ⚠️ 见下 |

### 已知边界

**本机被入侵时，同步内容对攻击者可见。** 这是所有本地同步方案的共同边界，
本项目不试图解决。缓解措施：

- 同步内容按需配置，不必要的一律不加白名单
- 磁盘启用加密
- 接收端数据库文件权限设为 `600`

## 密钥管理

### 生成

```bash
openssl rand -hex 32 > sync.key
chmod 600 sync.key
```

### 交换

**必须通过带外方式**——即不经过同步通道本身：

- 手动在两台机器间复制（U盘 / 手动键入）
- 或通过已建立信任的 Tailscale SSH 通道

不建议用邮件、聊天工具传输。

### 轮换

```bash
# 两端同时生成新密钥并交换，然后重启服务
```

轮换期间旧密钥签发的消息会被拒收，建议在同步空闲期执行。

## 配置文件安全

`collector.json` / `receiver.json` 含端点与路径信息，已被 `.gitignore` 屏蔽。
请勿重命名为其他名字提交。

生成自己的配置：

```bash
cp examples/collector.json.example collector.json
# 编辑，填入你的端点与路径
```

## 发布前检查清单

提交到公开仓库前确认：

- [ ] 未包含任何真实 IP 地址（公网、内网、Tailscale、IPv6）
- [ ] 未包含域名或主机名
- [ ] 未包含密钥、Token、密码
- [ ] 未包含会话数据或数据库文件
- [ ] 配置文件已被 `.gitignore` 屏蔽

可执行：

```bash
./scripts/pre-commit-check.sh
```

自动扫描常见敏感模式。
